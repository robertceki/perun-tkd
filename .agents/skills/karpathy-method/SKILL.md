# Spec -> Verify -> Record
Before multi-step implementation define why, scope, exclusions, assumptions and measurable DoD. Identify actual user approval; reuse unchanged authorization. Break work into small independently verifiable tasks.
Plan external checks before coding. Use current-state evidence, not self-report or markers. For complex work require independent Raphael review; a second model is optional and is not a prerequisite.
Record commands, exits, reviewed fingerprint and pending manual criteria. Do not call incomplete verification done.
Follow AGENTS.md for ownership, one correction, resume and re-review. Capture reusable decisions in .tmnt/knowledge; promote repeated useful procedures only when needed.
