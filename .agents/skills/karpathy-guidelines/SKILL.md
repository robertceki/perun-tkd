# Coding discipline
- Read relevant source before decisions; surface material assumptions.
- Implement only approved behavior; avoid speculative abstractions, unrelated refactors and unrequested dependencies.
- Respect exact writable-file scope and existing local changes.
- Match existing conventions; greenfield design tokens require an explicit initial design task, then reuse them.
- Verify observable behavior, negative cases and regressions appropriate to the change. Do not write tests that merely mirror implementation.
- Report unresolved checks and actual evidence plainly.
